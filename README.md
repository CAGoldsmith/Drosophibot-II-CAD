# Drosophibot II

Drosophibot II is a biomimetic robotic model of the fruit fly, _Drosophila melanogaster_, intended for use as a test platform for investigating the neuromechanics of legged locomotion. The robot is designed to be kinematically, dynamically, and sensorially similar to _Drosophila_ to facilitate the use of nervous system-inspired controllers and the collection of biologically-plausible sensory feedback presently unobtainable in the animal.

The robot was first published in [Goldsmith et al. 2024](https://iopscience.iop.org/article/10.1088/1748-3190/ad80ec), with additional information presented in [Goldsmith 2025](https://researchrepository.wvu.edu/etd/12842/).

This repository contains:
- 2024 Solidworks files for each robot component and peripherals (i.e., molds for the silicon feet, stand-ins for the actuators and computer).
- STL files for the robot's 3D printed components. Most plastic components for the robot were printed out of Onyx composite nylon on a Markforged MarkTwo 3D printer. Some parts additionally include continous carbon fiber reinforcement layers for added strength.

A full Bill of Materials (BoM) can be found [here](https://cloud.seatable.io/dtable/external-links/custom/drosophibot-ii-bom/). The BoM includes information on carbon fiber reinforcement and print settings for the printed components, as well as cost projections for the robot in USD.
It also includes the necessary components for the robot's power and signal PCBs, which can be found in the [`PCB-Schematics`](https://github.com/CAGoldsmith/PCB-Schematics) repository.
